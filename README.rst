Instruments
===========

Below is the list of instruments included in this plugin

Viewer0D
++++++++

* **ACM1000**: Alcatel ACM 1000 six-port gauge controller
* **OmniControl 200**: OmniControl 200 with pressure gauge connected (tested with PKR251)



Installation instructions for Alcatel plugins
=============================================

* PyMoDAQ 4
* Windows 10
* No drivers from Alcatel are required.
* Your PC should have serial ports (COM ports) to connect the controller. On Windows 10 you may need to install a driver to create virtual COM ports.

Installation instructions for Pfeiffer plugins
==============================================

* PyMoDAQ 5.0.x or later
* May require a virtual COM port driver: https://ftdichip.com/drivers/
